### Validation caveat

Windows validation was performed on the target Windows environment. Earlier Linux/WSL checks passed before the shared dependency directory was switched to Windows-native dependencies. The current shared `node_modules` directory contains Windows-native packages, so Linux/WSL tests are not currently repeatable from that directory without restoring or installing Linux-compatible dependencies. This is a dependency-environment limitation, not an application-defect result.
